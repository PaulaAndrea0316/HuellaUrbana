Huella Urbana

Descripción del proyecto

Huella Urbana es un proyecto web relacionado con los paseos de mascotas. Su propósito es presentar información sobre los servicios de paseo de perros, mostrando alternativas de paseos individuales y grupales.

Este proyecto busca ofrecer una página web sencilla, visual y fácil de navegar para las personas interesadas en los servicios de paseo de sus mascotas.

Tecnologías utilizadas

Para el desarrollo de este proyecto se utilizaron:

HTML5: estructura y contenido de la página web.

CSS3: estilos, diseño y presentación visual.

Imágenes: recursos gráficos utilizados para ilustrar el sitio web.
